# Launch UI - Local Rules

## Animations

- When moving elements vertically, use `em` units not `%`
- Animate containers, not individual items
- Use `flex` for layouts, avoid `position: absolute` when possible
- Container with `overflow: "hidden"` needs explicit `height`
- Keep animations simple - don't overcomplicate
- Use delays, staggers, and easings to make more organic animations

## Layout

- Follow 12-column grid system throughout the project
